# User Stories

1. **Как** студент, **я хочу** просматривать все доступные курсы, **чтобы** выбрать подходящие для изучения.

2. **Как** студент, **я хочу** записываться на курсы одним нажатием, **чтобы** начать обучение без лишних действий.

3. **Как** студент, **я хочу** видеть список своих курсов, **чтобы** отслеживать прогресс.

4. **Как** студент, **я хочу** выходить из курсов, **чтобы** освободить место для новых.

5. **Как** администратор, **я хочу** управлять пользователями и курсами, **чтобы** поддерживать актуальность данных.
